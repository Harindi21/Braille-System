# BrailleMaster

An accessibility web application that converts text and shapes into Braille, built with ASP.NET Core MVC.

## What it does
- Converts characters into Braille Unicode patterns.
- Maps shapes to Braille and computes shape geometry such as perimeter, for tactile output.
- Manage and search a catalog of Braille shapes and patterns.
- User accounts via ASP.NET Identity (sign up, log in, profile).

## Tech
- ASP.NET Core MVC (C#, .NET 6)
- Entity Framework Core with SQL Server
- ASP.NET Identity for authentication
- Razor views, HTML, CSS, JavaScript

## About
A 2023 project exploring assistive technology for people who are visually impaired.
